# Project Instructions

## Before Making Changes

- Inspect the existing codebase, understand its structure, framework, architecture, and conventions before touching anything.
- Follow the established framework, dependency versions, file organization, and coding style already present.
- Preserve all existing functionality — do not break working features or introduce unrelated changes.

## Frontend Design

- Use the **Swiss Grid** design skill for all UI work: components, pages, layouts, and visual styling.
- Produce polished, distinctive, production-quality interfaces — not generic templates.
- Build reusable, composable components and fully responsive layouts.
- Enforce consistent design tokens (colors, typography, spacing, border-radius) from the skill.
- Maintain WCAG AA accessibility: semantic HTML, correct contrast ratios, keyboard navigation.
- Optimize for performance: lazy-load assets, avoid unnecessary re-renders, keep bundle size lean.

## After Implementation

- Run the project's build command to confirm there are no compilation errors.
- Run the linter and fix any reported issues.
- Run available tests and confirm they pass before considering a task complete.
